# 试用法考模拟法庭短练

更新：2026-11-19。短练可以从已有课堂的知识点提问、经典创建和 Pro 创建进入。运行中的案卷由课堂读取；静态预览只演示视觉。详见[实现设计](legal-learning-implementation-design.md)。

## 从普通提问进入短练

启动当前工作树的应用，按启动终端显示的本地地址访问，确保已配置应用所需的数据库和课堂模型。之前启动的旧服务不会包含这次改动。

1. 打开已有课堂，在课堂问答中输入：**合同解除有什么条件？为什么违约时不一定能要求全额退款？** 使用默认的 Pi 聊天路径。
2. 等老师回答结束，查看回答下的短练卡。点击“开始短练”打开独立练习。无需另写案件，也可以忽略卡片继续提问。
3. 阅读三个编号材料，进入角色扮演，在对话里写下结论和理由，回应对手后完成阶段，查看答题复盘；“返回原课堂”回到来源课堂。
4. 对照输入“只解释合同解除的条件，不要演练”。预期只有原来的讲解。

若同一账户已经从这节课打开过同主题短练，卡片复用它。2–5 分钟是设计目标；仍要等待课堂讲解、对手回复及复盘。正式来源目前只配给固定案卷，其他主题可能显示“AI 生成的虚构教学案情”。

## 创建课程时安排短练

- 经典：在普通创建课堂入口输入“给法考学生讲解合同解除的条件，以及为什么不能把解除和全额退款等同”。在“审阅课程大纲”中查看短练页。也可手工新增或修改“项目式学习”，选“情景模拟”，再选择“合同交付与返款短练（固定案卷）”或 AI 生成选项。生成后打开对应场景，点“开始项目”。
- Pro：用同样的知识点做成小课，或要求“讲解后安排一个单争点短练”。Pro 可以读取 `legal-courtroom` Skill，再用 `generate_scene.pblConfig` 提交短练规格。字段和固定案卷能实际落盘；真实模型是否主动选择，要用你配置的模型另测。
- 自定义情景：手动选择法庭展示、填写情景简报与共同材料的要求，可以调用通用情景规划器。保存的舞台偏好在角色扮演阶段生效。旧课仅从界面切换视图，不会补入脚本或改变原评价模式。

## 查看独立席位预览

在项目根目录双击 courtroom-scene/打开法庭预览.cmd，可用默认浏览器打开静态页面，无需模型或数据库。预览可以切换示例、演示发言人、切换模拟学生头像并查看材料。

该页面使用教学示例，没有接入真实课堂对话、账户和案件运行状态。它与课堂里的 React 法庭视图是两个入口。

如需通过本地 HTTP 打开，在 courtroom-scene 目录运行：

```powershell
python -m http.server 3003 --bind 127.0.0.1
```

该命令运行时访问 http://127.0.0.1:3003/；本文不表示该服务现在正在运行。

## 验证记录的适用范围

2026-11-09 的历史浏览器验证覆盖手工情景和视图。2026-11-19 的自动化验证覆盖新入口、共有案卷和专用复盘，使用固定案例和模型替身，未用真实模型重放课堂。“短练”是单对手、单争点，没有完整的法官、证人或庭审程序。
